# Server function of plot module

Server function of plot module

## Usage

``` r
plotServer(id, path, file_type, title_format, variable = NULL, time = NULL)
```

## Arguments

- id:

  id of the module

- path:

  path to the file

- file_type:

  file type of file

- title_format:

  reactive list with title text and format arguments

- variable:

  variable from user selection

- time:

  time from user selection
