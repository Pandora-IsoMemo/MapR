# Observer to show table when display button is clicked

Observer to show table when display button is clicked

## Usage

``` r
observeShowTable(input, output, session, image_list, table_data, title_format)
```

## Arguments

- input:

  input object from server function

- output:

  output object from server function

- session:

  session from server function

- image_list:

  reactive image list

- table_data:

  reactive table data

- title_format:

  reactive list with title text and format arguments
