# Observer to show plot when display button is clicked

Observer to show plot when display button is clicked

## Usage

``` r
observeShowPlot(
  input,
  output,
  session,
  image_list,
  questionnaire,
  title_format
)
```

## Arguments

- input:

  input object from server function

- output:

  output object from server function

- session:

  session from server function

- image_list:

  reactive image list

- questionnaire:

  reactive questionnaire

- title_format:

  reactive list with title text and format arguments
